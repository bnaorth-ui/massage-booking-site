# เทสต์ที่รอตรวจสอบ (ไม่ถูกรันอัตโนมัติ)

17 ไฟล์นี้ **ไม่ผ่านทั้งก่อนและหลังย้ายเข้า repository** (ผลเดียวกันเมื่อรันทีละไฟล์ จึงไม่ใช่ปัญหาจากโหลดหนัก) ผมแยกมาไว้ที่นี่เพื่อให้ชุดเทสต์หลักสะอาดและเชื่อถือได้ ยังไม่ได้ลบ

รันเดี่ยวได้: `node _needs-review/ชื่อไฟล์.js` (ต้องรันจากโฟลเดอร์ `tests/`)

| ไฟล์ | อาการ | ที่น่าจะเป็น (ยังไม่ยืนยัน) |
|---|---|---|
| t_report.js, t_report2.js | รอ element ไม่เจอ (Timeout) | ถูกแทนที่ด้วย t_report_n.js |
| t_setsubs.js | Timeout | ถูกแทนที่ด้วย t_setsubs_n.js |
| t_admcontact.js, t_ppsubs.js, t_staffacct.js | Timeout | เมนูหรือขั้นตอนเปลี่ยนไปแล้ว |
| t_contact.js, t_ct_shot.js | ลำดับเมนู "แจ้งเตือน/รายการ/ติดต่อเรา" | เมนูเปลี่ยนเป็นแถบล่างแบบใหม่ |
| t_tabs.js, t_tabs2.js | จำนวน/ชื่อแท็บ | แถบเมนูเปลี่ยนไปแล้ว |
| t_done_dbg.js, t_perf_shop.js | ไม่มีข้อ PASS/FAIL | สคริปต์ตรวจดูตัวเลข ไม่ใช่เทสต์ |
| t_pts.js | ตัวเลือกแต้มสุดท้ายเป็น 450 ไม่ใช่ 400 และรูปแบบข้อความราคารวม | พฤติกรรมหรือข้อความเปลี่ยน ต้องตรวจว่าตั้งใจหรือไม่ |
| t_fav_none.js | ยังมีปุ่มโปรด/ตัวกรองทั้งที่ไม่มีข้อมูลโปรด | ต้องตรวจว่าตั้งใจหรือไม่ |
| t_rv_cust2.js | ไม่พบป้าย "ร้านใหม่" แทนคะแนน | ต้องตรวจ |
| t_watchui.js, t_pushui.js | สถานะป้ายแจ้งเตือน "เปิดอยู่" / Timeout | ต้องตรวจ (ใช้เว็บเซิร์ฟเวอร์พอร์ต 8099) |

อ่านคอลัมน์ขวาเป็นข้อสันนิษฐานจากชื่อไฟล์และข้อความที่ไม่ผ่านเท่านั้น หกไฟล์สุดท้าย (t_pts, t_fav_none, t_rv_cust2, t_watchui, t_pushui, t_staffacct) ควรให้คนตรวจว่าเป็นเทสต์เก่าหรือเป็นข้อบกพร่องจริงก่อนตัดสินใจลบหรือแก้
