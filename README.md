# massage-booking-site

ระบบจองนวดของสมาคมวิทยากรฝึกอาชีพคนตาบอด ประกอบด้วยเว็บ 4 หน้า แต่ละหน้าเป็นไฟล์ HTML ไฟล์เดียว ใช้ฐานข้อมูลและระบบสมาชิกของ Supabase

| โฟลเดอร์ | ผู้ใช้งาน | หน้าที่ |
|---|---|---|
| `customer/` | ลูกค้า | ดูร้านและบริการ จอง ดูประวัติ สะสมแต้ม รีวิว (ดูร้านได้โดยไม่ต้องล็อกอิน) |
| `shop/` | เจ้าของร้านนวด | จัดการร้าน บริการ พนักงาน โปรโมชั่น คิว และรายงาน |
| `staff/` | พนักงานนวด | ดูงาน รับงาน และรายได้ |
| `admin/` | แอดมินสมาคม | อนุมัติร้าน ตั้งค่าระบบ ดูรายงานและบันทึกการใช้งาน |

ทุกโฟลเดอร์มีไฟล์ `index.html` (ตัวหน้าเว็บ) และไฟล์ประกอบสำหรับติดตั้งแอปและแจ้งเตือน (`manifest.webmanifest`, `sw.js`, `push.js`, ไอคอน) กับ `_headers` ของ Cloudflare โฟลเดอร์ `customer/` มี `robots.txt`, `sitemap.xml` และไฟล์ยืนยัน Google เพิ่ม

## การนำขึ้นเว็บ

แต่ละโฟลเดอร์ถูกนำขึ้นเป็นเว็บของ Cloudflare Pages แยกกัน 4 เว็บ เมื่อมีการอัปโหลดเข้าสาขา `main` ของ GitHub ฐานข้อมูลอยู่ที่ Supabase (แผนฟรี ไม่มีสำรองอัตโนมัติ)

## เทสต์

เทสต์อัตโนมัติอยู่ใน `tests/` ใช้ข้อมูลจำลอง ไม่เรียก Supabase จริง และ GitHub Actions รันให้อัตโนมัติ วิธีรันดู `tests/README.md` และดูประวัติการเปลี่ยนแปลงที่ `CHANGELOG.md`
