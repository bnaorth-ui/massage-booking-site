# เว็บประชาสัมพันธ์ (เว็บที่ 5)

หน้าแรกของสมาคม ข่าวและกิจกรรม และบทความ สำหรับคนทั่วไป เปิดอ่านได้โดยไม่ต้องล็อกอิน
แอดมินเขียน แก้ เผยแพร่ หรือซ่อนเรื่องต่างๆ ได้ที่แอปแอดมิน เมนู **ระบบ > บทความและข่าว**

| ลิงก์ | หน้า |
|---|---|
| `/company/` | สำหรับบริษัท: จ้างหมอนวดไปนวดที่บริษัท และกฎหมายจ้างงานคนพิการ มาตรา 33/34/35 |
| `/` | หน้าแรก: แนะนำ ข่าวล่าสุด 6 เรื่อง ปุ่มจองนวด สมัครเปิดร้าน สมัครเป็นหมอนวด |
| `/news/` | รวมข่าวและบทความ (กรองได้ `?k=news` / `?k=work` / `?k=article`) |
| `/news/<เลข>` | อ่านเรื่องเต็ม มีปุ่มแชร์ LINE / Facebook / คัดลอกลิงก์ |
| `/sitemap.xml`, `/robots.txt` | สำหรับ Google (สร้างอัตโนมัติ) |

## สิ่งที่ต้องทำครั้งแรก (เจ้าของระบบทำเอง)

1. **ฐานข้อมูล:** รัน `supabase/sql/2026-11-17_site_articles.sql` แล้ว (17 พ.ย. 2569)
2. **เว็บใน Cloudflare Pages:** สร้างแล้ว (17 พ.ย. 2569 ผ่านตัวเชื่อมต่อ Cloudflare) ชื่อ `massage-home-bna` ผูกกับ GitHub สาขา `main` ตั้งค่าเหมือนอีก 4 เว็บ: Build command `exit 0`, Root directory `site`, Build output directory `.` (ต้องมี `exit 0` เพื่อให้ `functions/` ทำงาน) Cloudflare ผูกได้สูงสุด 5 เว็บต่อ repository เว็บนี้เป็นเว็บที่ 5
3. **ถ้าใช้ชื่ออื่นหรือโดเมนของสมาคม:** แจ้ง Claude ให้แก้ `SITE_URL` ในแอปแอดมิน (ปุ่ม "ดูบนเว็บ")
4. **Google:** ใน Google Search Console เพิ่มเว็บนี้ แล้วส่งแผนผังเว็บ `/sitemap.xml`

## ไฟล์

- `index.html` โครงหน้าเว็บ ปุ่ม และการกดเปลี่ยนหน้า อ่านข้อมูลจาก Supabase ด้วยกุญแจสาธารณะ เห็นเฉพาะเรื่องที่เผยแพร่
- `shared/views.js` ข้อความและเนื้อหาของทุกหน้า (แก้ข้อความที่นี่ที่เดียว) ใช้ทั้งในเบราว์เซอร์และบน Cloudflare
- `functions/_middleware.js` Cloudflare ใส่เนื้อหา ชื่อหน้า คำอธิบาย รูปแชร์ ข้อมูลโครงสร้างสำหรับ Google และกล่องติดต่อลงหน้าเว็บตั้งแต่ตอนส่ง ให้ Google / Bing / LINE / Facebook เห็นโดยไม่ต้องรันสคริปต์ หน้าที่ไม่มีตอบ 404
- `functions/sitemap.xml.js`, `functions/robots.txt.js` แผนผังเว็บและ robots.txt
- `shared/meta.js` โค้ดที่ functions ใช้ร่วมกัน
- `_headers` การเก็บแคชและความปลอดภัย
- รูปไอคอน (โลโก้สมาคม) และ `og-share.png` รูปแชร์ 1200x630 (โลโก้ + "จ้างงานคนตาบอดผ่านงานนวด ที่ขึ้นทะเบียนถูกต้อง" + ชื่อสมาคม) ถ้าเปลี่ยนรูป แก้คำบรรยาย `og:image:alt` ใน `index.html` ด้วย

## การเขียนเนื้อหา (ในแอปแอดมิน)

- เว้นบรรทัดว่าง = ย่อหน้าใหม่, บรรทัดขึ้นต้น `## ` = หัวข้อย่อย, ขึ้นต้น `- ` = รายการ, ลิงก์ `https://...` กดได้เอง
- ไม่รับ HTML (พิมพ์ `<` `>` ได้ตามปกติ แสดงเป็นตัวอักษร)
- มีรูปปกต้องใส่คำบรรยายรูปเสมอ (สำหรับคนที่ใช้โปรแกรมอ่านหน้าจอ) รูปถูกย่อเหลือกว้าง 1200 พิกเซล
